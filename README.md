# 証券口座 防衛チェック

証券口座を乗っ取られないための「やることチェックリスト」（スマホ向け1ページ）。

- 項目をタップするとチェックが付き、もう一度タップで外れる
- チェックは開いた端末のブラウザ内だけに保存されるので、リンクを配っても相手のチェックとは連動しない
- Safariの共有ボタン →「ホーム画面に追加」でアプリのように使える

2026年10月のSBI証券・SMBC日興証券の注意喚起（Apple・Googleアカウント乗っ取り経由で、クラウドに保存されたパスキーなどが悪用された疑い）をもとにしています。メニュー名は変わることがあるので、最終的には各社の公式ヘルプで確認してください。
